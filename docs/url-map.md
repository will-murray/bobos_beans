# URL map: bobosbeans.ca (current Shopify theme)

Captured from `https://bobosbeans.ca/sitemap.xml` and its child sitemaps on 2026-10-28.
The rebuild keeps every path identical so existing search rankings and inbound links carry over.

Hydrogen-owned paths handled in `src/middleware.ts` before Astro routing (no page files):
`/cart.js`, `/cart/add.js`, `/cart/<variantId>:<qty>`, `/checkout`, `/api/cart`,
`/api/predictive-search`, `/api/<version>/graphql.json`, `/.well-known/ucp`, `/api/ucp/mcp`,
`/products/<handle>?variant=<id>` (302 to option params), `/admin` (redirect to Shopify admin).

Not yet built: `/cart` (full cart page), `/account/*`. Add them at the same
standard paths when the time comes; the route-template manifest stays empty for them.

SEO metadata (title, meta description) is read from each resource's Shopify `seo` fields,
so what the merchant has set in Shopify admin is what renders. Every page emits a canonical
URL on the `https://bobosbeans.ca` origin.

`/agents.md` and `/robots.txt` are generated by Shopify on the live site; recreate them in
`public/` before launch if they should be kept.

Header and footer links are read from the Shopify `main-menu` and `footer` menus at request time,
so they track whatever the merchant sets in Shopify admin -> Online Store -> Navigation.
